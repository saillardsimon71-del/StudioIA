Le Studio est operationnel pour preparer le vrai episode 2 de "En prison".

## Corrections

- Alignement ASR : les mots contenant apostrophe ou trait d'union conservent les bons horodatages lorsqu'ils produisent plusieurs tokens. Le QC ne plante plus sur "C'est" ou "Abonne-toi".
- Import Director : les identifiants de plans invalides renvoient une erreur 422 au lieu d'une exception interne ou d'une conversion silencieuse.
- Decoupage LTX : les bruitages et silences sont rattaches au bon sous-plan, avec leur temps local, en conservant leur position dans l'echange.
- Post-doublage : provenance conservee, QC/cache/approbation et anciennes coupes invalides apres remplacement du son, sorties isolees par prise, reprise sans nouvelle synthese si les entrees sont identiques. Les tentatives rejetees ne sont plus retenues arbitrairement et le texte est controle avec le QC strict.
- Continuite : le scenario fige dans l'export final est utilise pour l'historique. Les anciens exports sans ces champs conservent leur comportement precedent. Les nouveaux exports figent aussi description, prompt et etat narratif.
- Orchestration : la verification du mode Director n'ouvre plus une base inutilement pour une tache sans projet. Cela corrige les dix echecs dependants de l'ordre de la suite generale.

Le post-doublage automatique reste desactive dans la configuration existante.
